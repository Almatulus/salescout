# SaleScout

## Запуск проекта

### 1. Установка зависимостей

Склонируйте репозиторий и перейдите в папку проекта:

Установите зависимости backend:

```bash
npm install
```

Установите зависимости frontend:

```bash
cd frontend
npm install
```

### 2. Запуск backend

В корневой папке проекта выполните:

```bash
npm run dev:server
```

Сервер запустится по адресу `http://localhost:3000`.

### 3. Запуск frontend

Откройте второй терминал, перейдите в папку проекта и выполните:

```bash
cd frontend
npm run dev
```

Откройте URL, который Vite выведет в терминале.

### 4. Проверка работы приложения

- Убедитесь, что frontend успешно загружается.
- Проверьте отображение списка товаров и результатов пересчёта цен.
- Убедитесь, что новые цены и причины расчёта отображаются корректно.

### 5. Запуск тестов

Для выполнения тестов откройте терминал и выполните команду ниже

```bash
npm test
```

Vitest выполнит тесты функции расчёта цен `calculatePrice`.

## API

**Endpoint:** `POST /reprice`

Метод рассчитывает новые цены для товаров, используя данные из `data/products.json`.

Запрос можно выполнить через Postman или curl:

```bash
curl -X POST http://localhost:3000/reprice
```

В ответ сервер возвращает массив результатов пересчёта цен.
